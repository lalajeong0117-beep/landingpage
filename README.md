# AUREN | Premium Fountain Pen Landing Page

프리미엄 만년필 브랜드 **AUREN**의 가상 브랜드 랜딩페이지입니다.

만년필이 가진 클래식한 감성과 장인정신을 현대적인 웹 디자인으로 표현한 반응형 웹사이트 프로젝트입니다.

브라운과 베이지 컬러를 중심으로 브랜드 특유의 따뜻하고 고급스러운 분위기를 구성했으며, 제품 이미지와 타이포그래피를 활용해 브랜드의 정체성을 전달하고자 했습니다.

---

## 01. 프로젝트 소개

| 항목 | 내용 |
|---|---|
| 프로젝트명 | AUREN |
| 프로젝트 유형 | 가상 브랜드 랜딩페이지 |
| 제작 목적 | 웹 퍼블리싱 및 반응형 웹 구현 |
| 개발 환경 | Visual Studio Code / Google Antigravity |
| 사용 기술 | HTML5, CSS3, JavaScript, jQuery |
| 반응형 기준 | PC / Tablet (1280px 이하) / Mobile (768px 이하) |

## 02. 프로젝트 목표

이번 프로젝트는 프리미엄 만년필 브랜드의 감성을 웹사이트에 담아내는 것을 목표로 제작했습니다.

단순히 제품을 소개하는 페이지가 아니라 브랜드의 역사, 제작 철학, 제품 컬렉션, 필기 경험, 선물 서비스를 하나의 흐름으로 구성하여 사용자가 브랜드의 가치를 자연스럽게 이해할 수 있도록 기획했습니다.

또한 다양한 화면 크기에서도 콘텐츠를 편리하게 확인할 수 있도록 반응형 레이아웃을 구현하는 데 중점을 두었습니다.

## 03. 사용 기술

**HTML5**

시맨틱 태그를 활용한 웹페이지 구조 설계 및 섹션별 콘텐츠 구성

**CSS3**

Flexbox를 활용한 레이아웃 구성, 미디어쿼리를 이용한 반응형 디자인, 배경 이미지 및 그라데이션 스타일링

**JavaScript / jQuery**

사용자 인터랙션 및 메뉴 동작 구현을 위한 스크립트 활용

**AOS (Animate On Scroll)**

스크롤에 따른 콘텐츠 등장 애니메이션 적용

※ jQuery 인터랙션 및 AOS는 실제 적용 상태에 따라 최종 업데이트 예정입니다.

## 04. 주요 섹션 소개

### 01. Hero

브랜드의 첫인상을 전달하는 메인 비주얼 영역입니다.

대표 이미지를 활용해 AUREN의 고급스러운 분위기를 표현하고, 메인 카피와 Discover Collection 버튼을 배치했습니다.

### 02. Heritage

브랜드가 추구하는 가치와 장인정신을 소개하는 영역입니다.

연도 타임라인과 만년필 제작 과정을 담은 이미지 3개를 활용하여 브랜드의 전통과 철학을 표현했습니다.

### 03. Crafted

만년필의 완성도와 섬세한 제작 요소를 소개하는 영역입니다.

펜촉(NIB), 래커(LACQUER), 균형감(BALANCE)을 중심으로 제품의 특징을 구성했습니다.

### 04. Collection

다양한 만년필 라인업과 제품 선택 기준을 소개하는 영역입니다.

6개의 특징 아이콘과 5종의 만년필 이미지를 활용하여 제품별 디자인과 개성을 보여 줍니다.

### 05. Writing Experience

만년필의 필기 경험을 시각적으로 전달하는 영역입니다.

이미지 위에 그라데이션 효과를 적용하고, 일반 만년필과 AUREN 만년필의 필기 경험을 비교하는 콘텐츠를 배치했습니다.

### 06. Gift & Engraving

만년필 선물 및 각인 서비스를 소개하는 영역입니다.

이니셜 각인, 펜촉 및 필기감 선택, 패키지와 메시지 등 3가지 서비스 항목을 카드 형태로 구성했습니다.

### 07. Brand Slogan

브랜드의 디자인 철학을 강조하는 영역입니다.

대형 만년필 이미지와 브랜드 메시지, View More 버튼을 활용해 시각적인 몰입감을 높였습니다.

### 08. Footer

브랜드 및 사업자 정보, 고객센터, 이메일, 이용약관, 개인정보처리방침 등 기본 정보를 정리했습니다.

## 05. 반응형 웹 디자인

CSS Media Query를 사용해 디바이스 크기에 따라 레이아웃이 변경되도록 구성했습니다.

| 구분 | 화면 크기 | 적용 내용 |
|---|---|---|
| Desktop | 1281px 이상 | PC 중심의 가로형 레이아웃 |
| Tablet | 769px ~ 1280px | 콘텐츠 간격 및 이미지 크기 조절, 모바일 내비게이션 |
| Mobile | 768px 이하 | 세로형 레이아웃, 텍스트 및 이미지 최적화 |

**반응형 구현 주요 사항**

- 디바이스별 내비게이션 구성
- Flexbox를 활용한 레이아웃 변경
- 이미지 크기와 비율 조정
- 텍스트 크기 및 여백 최적화
- 모바일 화면에서 콘텐츠 배치 재구성

## 08. 프로젝트 제작 포인트

**01. 브랜드 중심의 비주얼 구성**

만년필의 소재와 질감을 강조하는 이미지를 활용하고, 브랜드 컬러와 타이포그래피를 일관되게 적용했습니다.

**02. 섹션별 레이아웃 설계**

브랜드 소개부터 제품 컬렉션과 선물 서비스까지 각 섹션의 목적에 맞는 레이아웃을 구성했습니다.

**03. 반응형 퍼블리싱**

PC 레이아웃을 기반으로 1280px과 768px 미디어쿼리를 활용하여 디바이스별 콘텐츠 배치를 조정했습니다.

**04. 사용자 경험 개선**

직관적인 메뉴 구조, 버튼 디자인, 시각적 강조 요소를 활용하여 콘텐츠의 가독성과 사용 편의성을 고려했습니다.

## 09. 실행 방법

1. 프로젝트 저장소를 다운로드하거나 Clone합니다.
2. Visual Studio Code에서 프로젝트 폴더를 엽니다.
3. `index.html` 파일을 Live Server로 실행합니다.
4. 브라우저에서 페이지를 확인합니다.

## 10. 프로젝트 회고

이번 프로젝트를 통해 HTML과 CSS를 활용한 랜딩페이지 제작부터 반응형 웹 구현까지의 전반적인 과정을 경험했습니다.

특히 Flexbox와 Media Query를 활용하여 다양한 화면 크기에 맞게 레이아웃을 구성하고, 이미지와 텍스트의 위치 및 간격을 조정하는 과정을 통해 웹 퍼블리싱에 대한 이해도를 높일 수 있었습니다.

또한 하나의 브랜드 콘셉트를 전체 페이지에 일관되게 적용하면서 디자인 요소와 사용자 경험을 함께 고려하는 것의 중요성을 배웠습니다.
